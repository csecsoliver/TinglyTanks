# TinglyTanks

This is a simple tank game with some interesting mechanics. When you press the shoot button the tank switches into aiming mode, making the left/right controls rotate the barrel, and you can shoot by pressing the button again. Boost pads make you jump up and speed forward, bypassing the boxes in the way. While in the air the tank is in aim mode and triggers a shot when landing.

The controls can be set by scrolling down to reveal the menu.
